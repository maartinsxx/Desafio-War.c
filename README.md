# 🃏 Lógica do Projeto em C – Estrutura por Níveis de Evolução

Este repositório reúne o desenvolvimento completo de um projeto acadêmico em linguagem C, dividido em níveis de dificuldade que evoluem progressivamente: Nível Iniciante, Nível Intermediário e Nível Avançado.
Cada etapa acrescenta novas funcionalidades, técnicas e desafios lógicos, permitindo a construção gradual do conhecimento e o domínio mais profundo da linguagem.

A proposta deste trabalho é apresentar um sistema totalmente funcional, construído passo a passo, aplicando conceitos fundamentais de C, boas práticas de programação e estratégias de resolução de problemas. O projeto evolui de algo simples e estruturado até chegar a um sistema mais complexo, interativo e dinâmico.

## NÍVEL NOVATO – Cadastro de Territórios (Struct + Vetor)

Neste primeiro estágio, o objetivo é criar a estrutura fundamental do programa.
Aqui são definidos os elementos essenciais que compõem o sistema, como variáveis, entradas do usuário, organizações básicas de dados e a primeira lógica que dá vida ao projeto.

- O foco principal deste nível é compreender:

- Como armazenar informações

- Como capturar dados do usuário

- Como estruturar e exibir resultados de forma clara

- Como organizar um programa simples, porém funcional.

Esta etapa estabelece o alicerce necessário para que o projeto cresça de forma sólida nas fases seguintes.

## NÍVEL AVENTUREIRO – Aperfeiçoamento da Lógica e Novos Cálculos

No segundo nível, o projeto passa a ganhar profundidade.
Além das informações básicas, o sistema começa a realizar cálculos automáticos, manipular números com mais precisão e apresentar resultados derivados da entrada inicial.

Nesta fase, o aluno é levado a:

- Aplicar operações matemáticas mais complexas

- Criar variáveis derivadas

- Trabalhar com tipos numéricos como float e double

- Melhorar a exibição e o tratamento dos dados.

O programa torna-se mais completo e estratégico, refletindo situações mais próximas de problemas reais a serem resolvidos via programação.

## NÍVEL MESTRE – Comparações, Regras e Lógica de Decisão

No nível final, o projeto evolui para uma aplicação totalmente funcional, dinâmica e interativa.
Aqui são adicionados menus, decisões condicionais mais elaboradas, comparações entre valores e regras que definem diferentes resultados conforme a escolha do usuário.

Nesta etapa o programa implementa:

- Estruturas condicionais complexas (if-else, switch-case)

- Regras de comparação diferentes para tipos de atributos

- Escolhas dinâmicas feitas pelo jogador/usuário

- Entradas validadas para evitar erros

- Lógica inteligente para definir vencedores, empates ou resultados finais

É a fase que reúne tudo que foi aprendido anteriormente e transforma o sistema em um projeto completo, coeso e com múltiplas funcionalidades.

Aprendizados Gerais do Projeto

Ao longo do desenvolvimento, diversos conhecimentos essenciais foram exercitados:

- Declaração e manipulação de variáveis de diferentes tipos

- Entrada e saída de dados

- Operadores aritméticos e lógicos

- Estruturas condicionais e menus interativos

- Boas práticas de código e organização

- Tratamento e validação de entradas

- Lógica computacional aplicada a problemas reais

- Estruturação progressiva de sistemas

Este projeto demonstra que, mesmo com uma linguagem simples e poderosa como o C, é possível construir soluções completas, inteligentes e cheias de possibilidades.
